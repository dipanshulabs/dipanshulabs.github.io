Modified Rational Method — Triangular Hydrograph

V = 0.5 × (Q_in − Q_out) × T_s
T_s = T_c × Q_in / (Q_in − Q_out)
V = required storage volume (m³) Q_in = peak inflow (post-development) (m³/s) Q_out = permitted outflow (m³/s) T_c = time of concentration / storm duration (s) T_s = time to peak storage (s)
This is a preliminary sizing tool only. Final detention basin design must be verified using full hydrograph routing (e.g. level pool routing in InfoWorks ICM, SewerGEMS or HEC-HMS) with site-specific IDF data and topographic survey.
