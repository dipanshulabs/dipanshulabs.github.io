Import Workflow
Civil 3D: Map 3D → Import → Shapefile (.shp)
Bentley OpenRoads: Import → Shapefile or GeoJSON
SewerGEMS / WaterGEMS: Import → Shapefile → catchment polygon
QGIS: Drag and drop GeoJSON or Shapefile
ArcGIS: Add Data → Shapefile or GeoJSON
Drawing Tools
  • 1
    Search for your project location using the search bar at the top
  • 2
    Use the polygon tool (left toolbar on map) to draw your catchment boundary — click each vertex, double-click to finish
  • 3
    Use the polyline tool to draw the main flow path or stream — double-click to finish
  • 4
    Use the marker tool to place engineering points — outlets, manholes, culvert locations
  • 5
    Check the Stats tab for area, perimeter and flow path length. Enter elevations for slope calculation
  • 6
    Go to Q=CiA tab to run the Rational Method using your drawn catchment area
  • 7
    Go to Export tab and download as Shapefile (ZIP), GeoJSON, CSV or KML
Shapefile Import Guide
  • A
    Civil 3D: Map 3D tab → Import → FDO → select Shapefile → assign to drawing layer
  • B
    Bentley OpenRoads: Home → Primary → Import → select .shp file
  • C
    SewerGEMS: View → Flextables → Import Catchments → Shapefile
  • D
    QGIS: Drag the .zip directly — or Layer → Add Layer → Add Vector Layer
Notes
All coordinates are in WGS84 (EPSG:4326) geographic coordinates. The .prj file included in the Shapefile ZIP defines this projection. When importing into Civil 3D or Bentley, set your drawing coordinate system to WGS84 or reproject to your local grid (e.g. UTM Zone 39N for UAE) using QGIS or the built-in coordinate transformation tools.
