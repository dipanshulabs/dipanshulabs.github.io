Hazen-Williams (velocity form)

V = 0.849 × C × R^0.63 × S^0.54
V = velocity (m/s) C = Hazen-Williams roughness coefficient (dimensionless) R = hydraulic radius (m) = D/4 for full circular pipe S = hydraulic gradient = h_f / L (m/m) Q = V × A — multiply by pipe area for discharge (m³/s)

Darcy-Weisbach (headloss)

h_f = f × (L / D) × (V² / 2g)
h_f = friction headloss (m) f = Darcy-Weisbach friction factor (dimensionless) L = pipe length (m) D = internal pipe diameter (m) V = flow velocity (m/s) g = gravitational acceleration = 9.81 m/s²

Colebrook-White (friction factor — turbulent flow)

1/√f = −2 log₁₀ ( ε / (3.7D) + 2.51 / (Re √f) )
ε = equivalent pipe roughness height (m) Re = Reynolds number (dimensionless) Solved iteratively — or use the Swamee-Jain explicit approximation

While this calculator is under development, you can use the Roughness Reference table for Hazen-Williams C values, and the Reynolds Number Calculator to determine the flow regime before selecting a friction factor.
